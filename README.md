# FireCom Public

Public site for the FireCom app, served with GitHub Pages.

- Home: https://mainmaxton.github.io/FireCom-Public/
- Privacy policy: https://mainmaxton.github.io/FireCom-Public/privacy-policy.html
- Operating FireCom: https://mainmaxton.github.io/FireCom-Public/operating-firecom.html
- Incident map manual: https://mainmaxton.github.io/FireCom-Public/incident-map-manual.html
